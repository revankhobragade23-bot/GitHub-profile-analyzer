# GitHub Profile Analyzer

A simple Python project that uses the GitHub REST API to fetch and display public information about a GitHub user.

## Features

- Fetches GitHub username
- Displays user's name
- Shows followers and following
- Shows public repositories
- Shows public gists
- Displays GitHub profile URL
- Shows account creation date
- Handles invalid usernames

## Technologies Used

- Python
- GitHub REST API
- Requests
- JSON

## Requirements

- Python 3.x
- Requests library
